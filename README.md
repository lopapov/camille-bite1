# Camille Bite — GitHub Pages

Готовая статическая страница для GitHub Pages.

## Как запустить

1. Создай новый репозиторий на GitHub
2. Загрузи **все файлы и папки из этого архива** в корень репозитория
3. Открой **Settings → Pages**
4. В разделе **Build and deployment** выбери **Deploy from a branch**
5. Branch: **main**, folder: **/ (root)**
6. Нажми Save
7. Через некоторое время GitHub выдаст адрес сайта

Файл `index.html` уже находится в корне, поэтому дополнительная сборка не нужна.
